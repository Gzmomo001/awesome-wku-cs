## Student Projects and Tools

### Python IDLE Chinese Installer | Python IDLE 汉化包 中文安装器
- [Python IDLE Chinese Installer](https://github.com/Patrick-hbq/python-idle-cn-installer) - A simple Windows GUI installer for Python IDLE Chinese localization, useful for beginners who prefer a visual installation process. It may also be helpful for students taking `CPS3320`, where Python IDLE can be used for learning and practice.

- Python IDLE 汉化包 | 中文安装器 - 一个简单的 Windows 图形化工具，帮助 Python 初学者无需使用命令行，即可安装 Python IDLE 中文本地化环境。对于正在学习 `CPS3320` 课程、需要使用 Python IDLE 进行练习的学生也可能有所帮助。

> [!NOTE]
> 这里强烈建议CS专业的同学尽快熟悉命令行(shell), 降低对图形化界面的依赖. 下面的UV包管理器能直接管理所有python环境, 并且符合pytho官方规范.

#### 命令行安装python环境管理器 | UV

- 命令行安装命令
```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

- [官方文档](https://docs.astral.sh/uv/)

- UV Command Cheetsheet

```bash
uv init                  # 初始化新项目
uv add <pkg>             # 添加依赖
uv add --dev <pkg>       # 添加开发依赖
uv remove <pkg>          # 移除依赖
uv sync                  # 同步环境（安装所有依赖）
uv run <cmd>             # 在虚拟环境中运行命令
uv python pin <version>  # 固定 Python 版本
uv python install <ver>  # 安装 Python 版本
```
